# contracts/

The wire contract the server exports and the Swift app decodes. Change the server first (`server/AGENTS.md`), then this directory.

- `schema/*.json` is generated by `make contracts`; edit nothing there by hand, because `make check-contracts` compares it byte for byte with the TypeBox export.
- `fixtures/<name>[.<variant>].json` is hand-written and is the Swift side's source of truth: one file per variant a client must decode, realistic camelCase, fixed ids and timestamps, no real hosts or tokens. Swift decodes every fixture, and a fixture without a mapped Swift type fails the suite.
- `manifest.json` lists every route with its schema names, status codes and media types, binary and SSE routes included. A new route without an entry fails `make check-contracts`.
- `liveactivity.content-state` has no `inputName`: the device keeps it and the Swift `ContentState` declares it optional. `routeChip` and `headline` are omitted when absent, never null.
