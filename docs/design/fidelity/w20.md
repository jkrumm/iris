# Wave 20 U1: floating bars, scrubber, primary buttons

UI audit top-15 #1-5, #7, #8 (`ui-fidelity.md` of 2026-11-02). Reference: `feedback-round-2.md` and its mockups
(`r2-history-dark`, `r2-detail-*`, `r2-compose-dark`, `r2-history-filter-sheet-dark`).

Pictures (iPhone 17 / iOS 27.0, `w20/`, 2x downscaled): the "after" screens of this PR. The "before" screens are the audit's own
shots (`en-history-scroll-dark`, `en-banner-dark`, `en-detail-waterfall-dark`, `en-detail-failed-light`, `en-thread1-mid-dark`,
`de-filter-sheet-dark`, `en-composer-light`, `en-composer-typed-dark`, `en-mode-sheet-dark`), taken on the same simulator at the base
commit; they live in the gitignored `.artifacts/audit/`.

Method: a throwaway UI-test walk (not committed; `app.launch` with `-AppleLanguages (en|de)` and the light/dark appearance) attached a
screenshot per screen. Every fix is public API that iOS 26.0 has: a solid fill under glass, no private or 27-only tricks. iOS 26 draws
glass differently from 27, which is why the backing is a plain colour: it does not depend on the glass recipe. The iOS 26.6 look is a
device check (D1).

## What changed

| Audit item | Before | Fix | Picture |
|-|-|-|-|
| #1 History bottom stack (search capsule, Record accessory, tab bar, also the minimized tab bar under a take banner) | row text read through every glass layer | `floatingBarBackdrop(edge: .bottom)` on the search bar inset: the screen background down to the screen edge through the safe area, a 24 pt fade on the inner edge | `after-history-scrolled-dark`, `after-history-banner-dark` |
| #1 Detail action circles | content scrolled under them and showed through | same backdrop on the bottom inset, plus a solid panel disc under each glass circle | `after-detail-dark`, `after-detail-failed-light` |
| #1 Thread reply bar | answer text bled through the mic pill | same backdrop on the bottom inset | `after-thread-dark` |
| #1 Toast and failure banner | list text visible behind the glass pill | solid `Surface.panel` under the glass in `ToastBanner` (History, Detail, Thread, Mac) | not captured (needs a failed action) |
| #7 Status bar on History and Thread | ghost text, blur instead of a fill | `statusBarScrim()` is the same backdrop on the top edge; History and Thread now use it (Stats and Settings already did and keep working) | `after-history-scrolled-dark`, `after-thread-dark` |
| #2 Scrubber | system `Slider`: large white pill thumb, near-invisible track | `ThinScrubber`: 3 pt `Theme.divider` track, `Accent.fill` progress, 12 pt thumb, drag anywhere on it; the adjustable action (steps of 5 %), the label "Position" and the value "m:ss of m:ss" are kept | `after-detail-dark` |
| #3 Filter sheet "Show memos" | pale blue with a white label in dark | `PrimaryButtonStyle` | `after-filter-sheet-dark` |
| #4 "Start recording" | system blue | `PrimaryButtonStyle` | `after-record-as-de-light` |
| #5 Composer Send | disabled: white on light grey / black on grey; enabled in dark: pale blue with a black label | `Accent.fill` tint and white label when it can send; disabled: `Surface.elevated` with a muted label, readable in light and dark | `after-composer-dark` (typed), disabled state in the snapshot references |
| #8 Detail action symbols | speaker and reply filled, retry outline; disabled retry a ghost on a done memo | all three outline glyphs at one weight (semibold 20); retry is not drawn while there is nothing to retry | `after-detail-dark` |

`PrimaryButtonStyle` (`.buttonStyle(.primary)`): capsule, `Accent.fill`, `Accent.onFill` label, 0.8 opacity pressed; disabled a
`Surface.elevated` capsule with a hairline border and a `Ink.muted` label. `.controlSize(.large)` is the roomy variant of sheets.
The composer's Send sits in a toolbar, which draws its own prominent glass and ignores a custom `ButtonStyle`: it takes
`.borderedProminent` with the same tint and label colour set directly.

# Wave 20 U2: rows, sheets, chips

UI audit top-15 #6, #9-15 (`ui-fidelity.md` of 2026-11-02), plus the two leftovers U1 named above (the History empty-state button, the ghost
text behind the pinned day header). Reference: `feedback-round-2.md` and the mockups (`r2-history-dark`, `r2-history-filter-sheet-dark`,
`r2-compose-dark`, `r2-diagnostics-light`).

Pictures (iPhone 17 / iOS 27.0, `w20/u2-*`, 2x downscaled): English light and dark, and German light for the sheets, the outbox and the
thread. Method as for U1: a throwaway UI-test walk (not committed) attached a screenshot per screen.

## What changed

| Audit item | Before | Fix | Picture |
|-|-|-|-|
| #6 Outbox row | status beside the detail cut it to "Typed memo · 27 sec…."; Discard in system red; text buttons about one line high | status on its own line under the detail (which may take two lines); `Discard` in `Status.bad` (no `.destructive` role); Retry now and Discard are 44 pt high | `u2-outbox-light`, `u2-outbox-dark`, `u2-outbox-de-light` |
| #9 History row, thread marker | a chat row looked like any Hermes row | a speech-bubble glyph before the time on every row that opens a thread (`Memo.opensThread`) | `u2-history-scrolled-light`, `u2-history-chats-dark` |
| #9 History row, needs-route line | "Tap to decide" | "Journal suggested — tap to decide" when the memo carries `routeSuggestion`; else as before | `u2-history-light` |
| #9 History row, headline | cut at 60 characters, mid-word ("Pull Reques…") | cut at the last word boundary before 60; one unbroken word longer than that is still cut inside it | `u2-history-light` |
| #10 Filter sheet | no dots, half the sheet empty under the button | colour dots on route and state chips (white on a filled chip); "Show N memos" with N the rows the list will hold; the sheet is as tall as its content | `u2-filter-sheet-dark`, `u2-filter-sheet-de-light` |
| #11 Route sheet | title hard against a text "Cancel" pill | round close button (still `route.cancel`, VoiceOver "Cancel") and a principal title, centred in the bar | `u2-route-sheet-light`, `u2-route-sheet-dark`, `u2-route-sheet-de-light` |
| #12 Chip row jump | the subtitle line vanished when a chip filter listed no memo of today, the chips moved up 22 pt | the subtitle slot stays | `u2-history-chats-dark` |
| #13 Mode glyphs | Journal, Hermes, Chat had none, Auto/Tab/Transcribe had | one rule: every mode has its own glyph (Auto sparkles, Journal book, Hermes paperplane, Tab terminal, Chat bubble, Transcribe lines), in the composer chips and the Record long-press menu | `u2-composer-light`, `u2-composer-dark`, `u2-composer-de-light`, `u2-record-menu-dark` |
| #14 Thread, timestamps | "Oct 31, 2026 at 5:28 AM" on every turn | clock time only; the day is a labelled divider ("Today", "Sat, Oct 31") that opens every later exchange, and a "· <day>" after the turn count in the header for the first | `u2-thread-dark`, `u2-thread-de-light` |
| #14 Thread, code block | long lines clipped with no cue | a 20 pt fade on the trailing edge while the code reaches past it (the block still scrolls sideways) | snapshot `ThreadSnapshotTests/codeBlockOverflow` |
| #14 Thread, lists | numbers sat 23 pt left of the bullets | one marker column: both markers lead-aligned in the same 1.5 em | `u2-thread-dark`, snapshot `lists` |
| #14 Thread, number and unit | "2 s" could wrap between the two | a no-break space between a number and a known unit (ms, s, min, h, d, kB-TB, Hz, px, pt, %), prose only; code spans and fences are left alone | `u2-thread-dark` ("2 s and 8 s") |
| #15 Diagnostics id | wrapped mid-id | one line, scaled down to fit | `u2-diagnostics-light` |
| #15 Settings and Stats footnotes | the last footnote ended 17 px above the Record accessory | 20 pt bottom content margin on both scroll views | `u2-settings-bottom-light`, `u2-stats-bottom-light` |
| U1 leftover: empty-state button | `.borderedProminent` | `.buttonStyle(.primary)` | not drawn (needs an unconfigured app; no UI test or launch argument reaches it) |
