# Wave 22 U1: less chrome

PRD "Direction 2026-11-04" ("Less chrome"), `feedback-round-2.md` (binding). Pictures: iPhone 17 / iOS 27.0 (`w22/`, downscaled to 1000 px on the long
side) from a throwaway UI-test walk (not committed) on the fake stack at the pinned clock, one walk per appearance and language; the Mac window from
the app's own snapshot run (`IrisMac -IrisFakeData -IrisMacSnapshot`, system appearance dark). **Before** is A1's tip (PR #122, `w21-a1-apple-follows`),
**after** is this branch; same walk, same data, same simulator.

## What changed

| Screen | Before (A1) | After |
|-|-|-|
| History | 30 pt title block with the one-line summary and the [+] button, then the chips | chips are the first row under the status-bar scrim; the bottom row is search · filter · compose, three 44 pt targets, above A1's three-button record row and the tab bar |
| Stats, Settings, Diagnostics | `ScreenTitle` (30 pt bold) above the content | no title; the tab bar says where you are; Diagnostics' pushed bar carries its name |
| Memo detail (iOS) | chip + meta line, headline, player, steps, transcript, reply, actions line, device footer | headline, chip + meta line (time · length · cost), reply, actions line, player, transcript, **Details** (collapsed; open on a failed memo: step waterfall with cost and attempts per step, retry, ids, device); the bottom action bar stays |
| Memo detail (Mac pane) | headline, chip + meta line incl. device, reply, summary, transcript, steps table | same order, steps table and ids in a disclosure group "Details" (collapsed unless the memo failed); the meta line is time · length · cost |

## What the pictures show

- **History:** the title, the summary line and the corner [+] are gone; the chip row is the first thing under the status bar, and one more memo row fits above the bottom stack.
  The bottom stack reads search row (capsule, filter, compose), record row, tab bar, each separated by the 10 pt bar gap, no overlap, in English and German
  ("Transkribieren" and the longer German placeholder still fit the one row).
- **Compose twice:** the compose button in the search row and A1's "Text" button in the record row both open the composer. Both are the brief's, so both stay; say if one should go.
- **Detail:** a done memo ends in one collapsed "Details · 27.8 s · $0.05" line; a failed memo opens it on the failed step with its retry. The total moved up into the meta line
  (time · length · cost); ids and device are inside Details. A memo in its own Hermes session shows one id (the thread id equals the memo id there).
- **Stats / Settings:** no title; content starts at the 14 pt `sectionTop` under the scrim.
- **Mac:** the Details disclosure replaces the always-open steps table; the device left the meta line.

## Not rendered

- **Mac, failed memo and Details open:** the app's snapshot run (`MacSnapshotRun`, outside U1's files) only selects the done memo and a thread; the open state and the failed default are covered by `MacMemoDetailModelTests`.
- **Diagnostics:** unchanged apart from the title; its pushed bar is the system's inline bar.
